# 🎩 Монополия онлайн

Онлайн-монополия для игры с друзьями: хост создаёт комнату и отправляет ссылку, каждый играет со своего устройства.

Все названия улиц, карточки «Шанс» и «Казна», цены и деньги задаются **одним файлом — [`shared/board.json`](shared/board.json)**. Правите его → коммитите → хостинг передеплоит сам.

## Что поддерживается

- Комнаты по коду (4 символа) и ссылке `?room=КОД`, до 8 игроков
- Классические правила без аукционов: покупка, рента (монополия ×2), дома/отели с равномерной застройкой, залоги, тюрьма, налоги, банкротство, победа последнего выжившего
- **Кредиты**: в банке (ставка выше) или у другого игрока (ставка ниже). Проценты нарастают каждый ход должника; можно погасить досрочно, продлить (ставка растёт) — иначе кредитор забирает всё имущество и деньги. Другой игрок может «спасти» вас: гасит ваш долг, долг переходит к нему, а он получает 50% ренты с ваших улиц до выплаты
- **Обмен собственностью**: любой игрок в любой момент предлагает обмен полями и деньгами; получатель принимает или отказывается
- Реконнект после закрытия вкладки: игрок возвращается в свою сессию по ссылке
- Авторитетный сервер: читов нет, состояние только на сервере
- Русский интерфейс, работает на телефоне

## Локальный запуск

Нужен Node.js ≥ 20.

```bash
npm install
npm run dev        # сервер :3001 + клиент :5173 (открой http://localhost:5173)
```

Прод-сборка (один процесс раздаёт и клиент, и websocket):

```bash
npm run build
npm start          # http://localhost:3001
```

Тесты движка:

```bash
npm test
```

## Деплой

### Render.com (бесплатно)

1. Запушьте репозиторий на GitHub (инструкция ниже).
2. Зайдите на [render.com](https://render.com), **New → Web Service**, подключите GitHub-репозиторий.
3. Настройки подхватятся из `render.yaml`, но если вручную:
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `npm start`
   - **Runtime:** Node
4. Create Web Service — через пару минут получите адрес вида `https://ваш-сервис.onrender.com`.

Минус бесплатного тарифа: сервис засыпает после 15 минут бездействия, первый вход потом занимает ~30 секунд. Во время игры засыпания не будет.

### Railway (альтернатива, ~$5/мес, без засыпания)

1. [railway.app](https://railway.app) → **New Project → Deploy from GitHub repo**.
2. Railway сам определит Node: добавьте только переменную, если попросит — не нужна, всё в `package.json`.
3. **Settings → Networking → Generate Domain** — готово.

### Пуш на GitHub (если ещё нет репозитория)

```bash
cd <папка проекта>
git remote add origin https://github.com/ВАШ_ЛОГИН/monopoly.git
git push -u origin main
```

## Как поменять контент: `shared/board.json`

Любая правка файла + `git push` = перезапуск игры с новым контентом.

### Общие правила

```json
"rules": {
  "startMoney": 1500000,   // стартовый капитал
  "goSalary": 200000,      // зарплата за круг
  "jailFine": 50000,       // залог в тюрьме
  "housesLimit": 32,       // лимит домиков в банке (null = без лимита)
  "hotelsLimit": 12        // лимит отелей (null = без лимита)
}
```

`meta.currency` — символ валюты (например `"₽"` или `"$"`).

### Кредиты (`rules.loans`, секция необязательна)

```json
"loans": {
  "bankRate": 0.1,           // ставка банка за ход должника (10%)
  "playerRate": 0.05,        // ставка займа между игроками (5%)
  "termTurns": 10,           // срок: через сколько ходов должника кредит подлежит выплате
  "extendRateFactor": 1.5,   // продление: ставка умножается на это
  "maxExtensions": 2,        // сколько раз можно продлевать
  "maxPrincipal": 1500000,   // максимальная сумма тела кредита
  "rescueSharePercent": 50   // доля ренты спасателю
}
```

Как это работает: проценты начисляются в начале каждого хода должника. Когда срок вышел, заёмщик должен на своём ходе погасить долг или продлить — иначе в конце хода кредитор (банк или игрок) забирает всё имущество и деньги, должник выбывает. Активный кредит — залог: при любом банкротстве всё уходит кредитору по кредиту. Кредитор-игрок может «спасти» должника: платит долг кредитору, долг переходит к нему (та же ставка), и он получает `rescueSharePercent`% ренты с улиц должника, пока долг не выплачен. Одновременно может быть только один кредит.

### Поля (`tiles`, ровно 40 штук)

Типы полей:

| Тип | Обязательные поля |
|---|---|
| `go`, `jail`, `free-parking`, `go-to-jail`, `chance`, `chest` | только `name` |
| `tax` | `name`, `amount` |
| `street` | `name`, `group` (ключ из `groups`), `price`, `houseCost`, `rent` — массив 6 чисел: [база, 1 дом, 2, 3, 4, отель] |
| `railroad` | `name`, `price`, `rent` — массив 4 чисел (по числу вокзалов у владельца) |
| `utility` | `name`, `price`, `rentMultiplier` — [x1, x2] (бросок × множитель) |

Названия полей покупаемых типов (`street`/`railroad`/`utility`) должны быть уникальными — карточки ссылаются на них по имени. «Шанс» и «Казна» могут повторяться сколько нужно.

### Карточки (`chance` и `chest`)

Каждая карточка: `text` (что напечатано на карте) + `effect`. Типы эффектов:

```json
{ "type": "money", "amount": -50000 }                  // +/- деньги (минус = платишь в банк)
{ "type": "moneyFromEach", "amount": 100000 }          // получить с каждого игрока
{ "type": "moneyToEach", "amount": 100000 }            // заплатить каждому игроку
{ "type": "moveTo", "tile": "Тверская" }               // перейти на поле (имя или индекс)
{ "type": "moveBy", "steps": -3 }                      // пройти N шагов (минус = назад)
{ "type": "goToJail" }
{ "type": "getOutOfJail" }
{ "type": "nearestRailroad" }                          // к ближайшему вокзалу, рента ×2
{ "type": "nearestUtility" }                           // к ближайшему предприятию, бросок ×10
{ "type": "repairs", "perHouse": 50000, "perHotel": 200000 }
```

При загрузке сервер валидирует конфиг и покажет понятную ошибку, если что-то не так.

## Структура проекта

```
shared/board.json      ← ВЕСЬ ваш контент (улицы, карты, цены)
shared/src/            ← общие типы и валидатор конфига
server/src/game/       ← игровой движок (тесты: engine.test.ts)
server/src/            ← Socket.IO: комнаты, реконнект, раздача клиента
client/src/            ← React: доска, панели, модалки
```
